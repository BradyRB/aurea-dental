# Aurea Dental Studio

A premium dental clinic landing page designed to showcase modern frontend engineering, luxury healthcare branding, motion design, and responsive user experiences.

## Overview

Aurea Dental Studio is a production-quality marketing website for a high-end dental practice. The project focuses on combining premium visual design with modern web development practices to create a polished and engaging patient experience.

The goal was to build a healthcare-focused brand experience that feels modern, trustworthy, and sophisticated while maintaining excellent usability and performance.

## Features

* Premium healthcare branding
* Responsive design across mobile, tablet, and desktop
* Smooth scroll-reveal animations
* Interactive motion effects with Framer Motion
* High-quality dental imagery
* Modern component-based architecture
* Accessibility-conscious implementation
* SEO-friendly metadata
* Optimized image handling with Next.js
* Production-ready deployment workflow

## Tech Stack

* Next.js 15
* TypeScript
* Tailwind CSS
* Framer Motion
* React
* Next/Image

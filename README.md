# Aurea Dental Studio

Premium frontend-only landing page for a high-end dental clinic.

## Stack

- Next.js 15 App Router
- TypeScript
- Tailwind CSS
- shadcn-style UI primitives
- Lucide React
- React Hook Form
- Zod
- next/image

## Run Locally

```bash
npm install
npm run dev
```

Generated placeholder imagery lives in `public/images` and can be replaced with final clinic photography without changing component code.
